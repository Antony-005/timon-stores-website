# Timon Stores Ltd — Website

Business website for Timon Stores Ltd, a regional FMCG distributor based in Oyugis, Homa Bay County, Kenya.

## Stack
Static site built with Vite (HTML/CSS/JS, no backend framework).

## Getting started
\`\`\`
npm install
npm run dev
\`\`\`

## Build
\`\`\`
npm run build
\`\`\`
Outputs to /dist — deployable to any static host (Netlify/Vercel/GitHub Pages).
